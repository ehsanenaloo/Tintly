## Why Tintly

Most of the web is a white screen. At night it glares. For a long read it tires you. For about one man in twelve, it also hides information: a red error next to a green "done", a chart with two lines in colors that look the same.

Tintly changes the colors of every page you open and leaves the layout and the content alone. It does not flip colors blindly. It reads the page's own style sheets and writes new colors for them, so pictures, logos and charts still look right and big pages stay fast.

---

## Five ways to see a page

One control in the toolbar window. One click to change.

| Mode | For | What you get |
|---|---|---|
| **Dark** | Evenings, dim rooms, OLED screens | A dark theme with seven palettes: Default, Graphite, AMOLED black, Midnight blue, Solarized Dark, Nord and Gruvbox. Text always keeps a contrast of at least 4.5 to 1 |
| **Light** | Bright rooms, daytime reading | A clean light theme with four palettes: Default, Warm paper, Cool gray and High contrast |
| **Paper** | Long reading on any screen | A warm paper color, soft ink, a little less white and less blue light. A calm page that feels like print |
| **E-ink** | Maximum calm, black and white screens | White paper, black ink and 8 grays. Pictures turn gray. Animations, shadows and smooth scrolling stop |
| **Original** | Keeping the page's own colors | Tintly leaves the colors alone and only applies what you choose, such as color vision correction or link underlines |

In Dark and Light, sliders for brightness, contrast, sepia, grayscale and night shift fine-tune the look.

## Color vision correction

**If red and green look alike to you, Tintly moves them apart.**

About 8 percent of men and 0.5 percent of women have some form of color blindness. A web page does not care. Status lights, charts, maps, diffs, graphs and error messages lean on colors that can look identical.

Tintly changes the colors of the page itself, so you do not need a special site or a screenshot tool.

- **Pick your type.** Red weak (protan), Green weak (deutan) or Blue weak (tritan).
- **Set the strength.** From 0 to 100 percent, for a mild form or a strong one.
- **Choose how far colors move.** The Color boost slider decides how much soft and strong colors change.
- **See it before you decide.** A preview row shows common colors as the page has them and after the filter, and how a person with your type may see each.
- **Brightness is kept.** Grays, black and white stay as they are, and so does how light or dark each color is. For red weak vision, reds are lifted so they look as bright as they should.
- **Everything follows.** Pictures, video, icons and background images use the same filter. You can turn that off.
- **Works in every mode.** Use it with Dark, Light and Paper, or alone in Original mode, so the page keeps its own look and only the confusing colors move.
- **Underline links.** Find a link without relying on its color.
- **Per site.** Give one site its own filter and strength.

The same filter list also has Grayscale, Grayscale inverted and Inverted for the people who want a gray or inverted page.

## Made for reading

Paper and E-ink turn a busy page into something that feels like a book.

- A paper color you can change, with quick choices: Cream, Soft yellow, Light gray and White.
- **Brightest white** and **Less blue light** sliders for late evenings.
- Pictures follow the color setting, gray or stay as they are.
- Optional thicker lines for buttons and fields, and a thick focus ring.
- Gray levels from smooth to 2, 4, 8 or 16.
- Stop animations, transitions, smooth scrolling and shadows, each on its own.

## Smart where it counts

| | |
|---|---|
| **Four engines** | Dynamic reads the style sheets and writes new colors. Filter and Filter+ start at once and suit very large pages. Static colors only the parts a stored fix names. Automatic picks one for you |
| **The site's own dark theme** | If a page has a dark theme of its own, Tintly turns it on and checks the result. Pages that are already dark are left as they are |
| **Pictures that still look right** | Dark logos and charts on white are inverted. Very bright photos are dimmed. Square codes keep a white plate so they scan |
| **No white flash** | A quick dark version shows while the full theme loads |
| **Readable text** | Text keeps its contrast after the theme is applied |

## Yours to control

- **Each site on its own.** Turn a site on or off, or give it its own mode, engine and sliders. Or use Tintly only on the sites you pick.
- **A schedule.** Set hours, follow sunset and sunrise at your place, or follow your system's dark mode.
- **Presets.** Save a look and apply it again with one click.
- **Site fixes.** Give a site its own CSS, mark logos to invert and leave some colors or pictures alone. Copy a fix or add one from someone else.
- **Backup and sync.** Export and import your settings. Sync through your browser account is optional and off by default.
- **Keyboard first.** Shortcuts: `Alt+Shift+D` for the extension and `Alt+Shift+S` for the current site. All windows work with the keyboard and follow reduced motion and forced colors.

## Private by design

- Tintly collects nothing. No telemetry, no analytics, no account and no remote settings.
- Your settings, site rules, presets and fixes stay in your browser.
- The only requests it makes are to download a style sheet or a picture of the page you are on, when the browser does not let the page code read it. It sends no cookies with them.
- It changes colors, fonts and the color-scheme hint. It does not change what a page shows, sends or stores. A site that is switched off gets nothing from Tintly.

| Permission | Why |
|---|---|
| `storage` | To keep your settings |
| `scripting` | To add the color engine to the pages you open |
| Access to all sites | To color the pages you open |
| `contextMenus`, optional | To show a menu item, only if you turn it on |
| `alarms`, optional | To switch pages on and off at the times of your schedule, only if you allow it |

Full text: [Privacy policy](docs/PRIVACY.md).

| Browser | Minimum | How |

## Notes for site authors

- Ask Tintly to leave your page alone with `<meta name="tintly" content="off">` or `<html data-tintly="off">`.
- Offer your own dark theme: declare `color-scheme: light dark` and write dark colors in `@media (prefers-color-scheme: dark)`. Tintly turns them on when the page is dark and the text is readable.
- Say that your page supports one scheme only with `color-scheme: only light` or `only dark`, and Tintly respects it. A visitor can still turn Tintly on for the site by hand.

## FAQ

**Does Tintly send my data anywhere?** No. See [Private by design](#private-by-design).

**A page looks wrong. What can I do?** Try another engine in the toolbar window, or turn Tintly off for that site. Then open the [page looks wrong form](https://github.com/ehsanenaloo/Tintly/issues/new?template=site_breakage.yml) with the address, the mode and the engine.

**What is the difference between Paper and E-ink?** Both give a calm page for reading. E-ink starts with no color. Paper keeps a little color and lowers the brightest white and the blue light. A Color setting changes this for both.

**Can I use Tintly only on some sites?** Yes. Choose to use it only on the sites you pick, or switch single sites off.

## Develop

Node.js 22 or newer.

```bash
npm install
npm run check          # static checks, type check and unit tests
npm run build          # Chrome and Edge package in dist/
npm run build:firefox  # Firefox package in dist/
npm run lint:firefox   # builds the Firefox package and runs the add-on linter on it
npm run test:browser   # real Chromium; run `npx playwright install chromium` once
npm run test:firefox   # real Firefox; needs Firefox installed
npm run test:perf      # speed and size budgets
```

`.npmrc` sets `ignore-scripts=true`, so installing a package never runs its install script. More in [docs/TESTING.md](docs/TESTING.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```text
extension/            the extension exactly as it ships (no build step)
  background/         service worker and its modules
  content/            gate, engines and the small page-world hook
  pages/              toolbar window, settings page, fix editor
  shared/             settings, storage, languages, limits
  data/               site data written by npm run data:build
  _locales/           browser-level strings
data-src/             source of the site data (fixes and the dark-site list)
scripts/              validation, packaging, data tools
tests/                unit, browser, Firefox and performance tests
types/                type declarations
docs/                 privacy policy, architecture, testing and translating notes
.github/              community files, issue forms, workflows, README images
```
