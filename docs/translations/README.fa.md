# Tintly - Dark Mode & Reading Modes

**صفحه‌های وب را تاریک، روشن یا شبیه کاغذ ببینید. جدا برای هر سایت، با زمان‌بندی و بدون ردیابی.**

افزونهٔ رایگان و متن‌باز برای Chrome، Edge و Firefox.<br>
فقط روی دستگاه خودتان کار می‌کند. بدون حساب کاربری، بدون آمارگیری و بدون تنظیمات از راه دور.

## چرا Tintly

بیشتر صفحه‌ها برای زمینهٔ سفید ساخته شده‌اند. حالت تاریکی که فقط همهٔ رنگ‌ها را وارونه کند، تصویرها را خراب می‌کند و صفحه‌های بزرگ را کند می‌کند. Tintly شیوه‌نامه‌های هر صفحه را می‌خواند، رنگ‌های تازه برایشان می‌نویسد و چیدمان و محتوا را دست‌نخورده می‌گذارد. این کار را بدون فرستادن هیچ چیز به جایی انجام می‌دهد.

## ویژگی‌ها

- **چهار حالت در یک کنترل.** تاریک، روشن، کاغذ و E-ink. با یک کلیک حالت عوض می‌شود. «کاغذ» و E-ink صفحه‌ای آرام از کاغذ و جوهر برای مطالعه می‌دهند، با خیرگی و نور آبی کمتر، تصویرهای خاکستری یا ملایم و بدون بخش متحرک.
- **چهار موتور.** «پویا» شیوه‌نامه‌ها را می‌خواند و رنگ تازه می‌نویسد. «فیلتر» و «فیلتر+» بی‌درنگ شروع می‌کنند و برای صفحه‌های خیلی بزرگ مناسب‌اند. «ثابت» فقط بخش‌هایی را رنگ می‌کند که یک اصلاح ذخیره‌شده نام برده است. حالت «خودکار» از «پویا» استفاده می‌کند.
- **کنترل جدا برای هر سایت.** هر سایت می‌تواند روشن، خاموش یا دارای حالت، موتور و لغزندهٔ خودش باشد. می‌توانید Tintly را فقط روی سایت‌هایی که انتخاب می‌کنید به کار ببرید.
- **زمان‌بندی.** ساعت‌های مشخص، غروب تا طلوع در محل شما، یا حالت تاریک سیستم. مجوز اختیاری alarms سوییچ را دقیق می‌کند و صفحه‌های خاموش را از کد Tintly خالی نگه می‌دارد.
- **تم تاریک خودِ سایت.** اگر صفحه تم تاریک خودش را دارد، Tintly آن را روشن می‌کند و نتیجه را می‌سنجد. اگر صفحه تاریک نباشد یا خواندن متن سخت شود، از رنگ‌های خودش استفاده می‌کند.
- **صفحه‌هایی که از قبل تاریک‌اند دست‌نخورده می‌مانند.** صفحه‌ای که `color-scheme: only light` یا `only dark` اعلام کند، محترم شمرده می‌شود، مگر اینکه این را خاموش کنید.
- **پالت‌ها و لغزنده‌ها.** پالت‌های تاریک: پیش‌فرض، Graphite، AMOLED black، Midnight blue، Solarized Dark، Nord و Gruvbox. پالت‌های روشن: پیش‌فرض، Warm paper، Cool gray و High contrast. روشنایی، کنتراست، سپیا و خاکستری. رنگ فونت، ضخامت متن، نوار پیمایش و رنگ انتخاب.
- **الگوها.** یک ظاهر را ذخیره کنید و دوباره به کار ببرید، یا در قاعدهٔ یک سایت نگه دارید.
- **ویرایشگر اصلاح.** برای یک سایت CSS جداگانه بنویسید، آرم‌هایی را که باید وارونه شوند علامت بزنید و بعضی رنگ‌ها یا تصویرها را دست‌نخورده بگذارید. یک اصلاح را کپی کنید، اصلاح دیگران را اضافه کنید و حذف را واگرد کنید.
- **متن خوانا.** پس از اعمال تم، متن حداقل کنتراست ۴٫۵ به ۱ را نگه می‌دارد. تصویرهای صفحهٔ تاریک بررسی می‌شوند: آرم‌های تیره و نمودارهای روی زمینهٔ سفید وارونه می‌شوند و عکس‌های خیلی روشن کمی تیره می‌شوند.
- **پشتیبان‌گیری و همگام‌سازی.** تنظیمات را خروجی بگیرید و وارد کنید. همگام‌سازی با حساب مرورگر اختیاری و در ابتدا خاموش است. CSS سفارشی که از فایل یا همگام‌سازی برسد، تا وقتی آن را نخوانید و روشن نکنید خاموش می‌ماند.
- **زبان‌ها.** فارسی، انگلیسی، عربی و عبری، چپ‌به‌راست و راست‌به‌چپ.
- **صفحه‌کلید و دسترسی‌پذیری.** پنجره‌ها با صفحه‌کلید کار می‌کنند، جای تمرکز را نشان می‌دهند، تنظیم کاهش حرکت و رنگ‌های اجباری را دنبال می‌کنند و در پنجرهٔ باریک جا می‌شوند. میانبرهای پیش‌فرض: `Alt+Shift+D` برای افزونه و `Alt+Shift+S` برای سایت فعلی.

راهنمای کاربر در [enaloo.com](https://enaloo.com/apps/tintly/) خوانده می‌شود و در این مخزن نیست.

## نصب

پیوند فروشگاه‌ها به‌زودی اضافه می‌شود. افزونه هنوز در هیچ فروشگاهی نیست.

- برای **Chrome و Edge** نسخهٔ ۱۱۹ یا بالاتر: به‌زودی.
- برای **Firefox** نسخهٔ ۱۲۸ یا بالاتر: به‌زودی.
- **از روی کد:** این مخزن را کلون کنید، `npm install` را اجرا کنید و پوشهٔ `extension/` را بارگذاری کنید. در Chrome یا Edge صفحهٔ `chrome://extensions` را باز کنید، Developer mode را روشن کنید و Load unpacked را بزنید. برای Firefox دستور `npm run build:firefox` را اجرا کنید و فایل zip پوشهٔ `dist/` را در `about:debugging` به‌عنوان افزونهٔ موقت بارگذاری کنید.

## حریم خصوصی و مجوزها

- افزونه چیزی جمع نمی‌کند. ردیابی، آمارگیری، حساب کاربری و تنظیمات از راه دور ندارد.
- تنها درخواست‌هایش برای دانلود یک شیوه‌نامه یا تصویر از همان صفحه‌ای است که در آن هستید، آن هم وقتی مرورگر اجازهٔ خواندنش را به کد صفحه نمی‌دهد. هیچ کوکی همراه این درخواست‌ها فرستاده نمی‌شود.
- تنظیمات، قاعده‌های سایت، الگوها و اصلاح‌ها در مرورگر شما می‌مانند. اگر همگام‌سازی را روشن کنید، مرورگرتان آن‌ها را از راه حساب خودتان کپی می‌کند.
- افزونه فقط رنگ‌ها، فونت‌ها و نشانهٔ color-scheme را تغییر می‌دهد. آنچه صفحه نشان می‌دهد، می‌فرستد یا ذخیره می‌کند عوض نمی‌شود. سایتی که خاموش است چیزی از Tintly نمی‌گیرد.

| مجوز | دلیل |
| --- | --- |
| `storage` | نگه‌داشتن تنظیمات شما |
| `scripting` | افزودن موتور رنگ به صفحه‌هایی که باز می‌کنید، و گذاشتن آن در زبانه‌هایی که هنگام نصب، به‌روزرسانی یا روشن‌کردن یک سایت از قبل باز بوده‌اند |
| دسترسی به همهٔ سایت‌ها | رنگ‌کردن صفحه‌هایی که باز می‌کنید |
| `contextMenus`، اختیاری | نمایش یک گزینه در منوی راست‌کلیک، فقط اگر روشنش کنید |
| `alarms`، اختیاری | روشن و خاموش‌کردن صفحه‌ها در ساعت‌های زمان‌بندی. فقط اگر اجازه بدهید |

در Firefox مجوز منوی راست‌کلیک `menus` نام دارد. Firefox نمی‌تواند این مجوز و `alarms` را بعداً بخواهد، پس بستهٔ Firefox هر دو را از ابتدا دارد. هیچ‌کدام هنگام نصب هشدار نشان نمی‌دهند. متن کامل: [سیاست حریم خصوصی](../../docs/PRIVACY.md) (به انگلیسی).

## زبان‌ها

پنجره‌های Tintly به فارسی، انگلیسی، عربی و عبری است. فارسی، عربی و عبری راست‌به‌چپ‌اند و کل پنجره آینه می‌شود. منبع متن‌ها انگلیسی است. سه زبان دیگر ترجمهٔ ماشین‌یار هستند و هنوز هیچ گویشور بومی آن‌ها را بازبینی نکرده است. اگر متنی غلط یا نامناسب دیدید، از [فرم اصلاح ترجمه](https://github.com/ehsanenaloo/Tintly/issues/new?template=translation_fix.yml) استفاده کنید یا درخواست ادغام بفرستید. [TRANSLATING.md](../TRANSLATING.md) (به انگلیسی) توضیح می‌دهد چگونه یک متن را اصلاح کنید یا زبانی را اضافه کنید.

## نکته برای سازندگان سایت

صفحه می‌تواند با یک متا تگ در head بخواهد Tintly دست به آن نزند: `<meta name="tintly" content="off">`، یا با یک ویژگی روی عنصر ریشه: `<html data-tintly="off">`. اگر بازدیدکننده Tintly را برای آن سایت دستی روشن کرده باشد، حرف بازدیدکننده مقدم است.

صفحه‌ای که تم تاریک خودش را دارد می‌تواند آن را عرضه کند. `color-scheme: light dark` را اعلام کنید و رنگ‌های تاریک را در `@media (prefers-color-scheme: dark)` بنویسید. Tintly این قاعده‌ها را روشن می‌کند و اگر صفحه تاریک شود و کنتراست متن دست‌کم ۴٫۵ به ۱ باشد، نگهشان می‌دارد.

صفحه می‌تواند اعلام کند که فقط یک طرح رنگ را پشتیبانی می‌کند: `color-scheme: only light` یا `only dark`، در CSS روی ریشه یا body، در ویژگی style ریشه یا body، یا در `<meta name="color-scheme" content="only light">`. Tintly آنگاه صفحه را همان‌طور که هست می‌گذارد، اگر انتخابش با صفحه در تضاد باشد: صفحه‌ای که `only light` می‌گوید در حالت تاریک دست‌نخورده می‌ماند و صفحه‌ای که `only dark` می‌گوید در همهٔ حالت‌ها. حالت‌های روشن، کاغذ و E-ink صفحهٔ `only light` را مثل همیشه رنگ می‌کنند. سایتی که بازدیدکننده دستی روشن کرده باشد، هر چه صفحه بگوید رنگ می‌شود، و یک کلید در تنظیمات این احترام را خاموش می‌کند. متا تگ و ویژگی style پیش از اولین نقاشی خوانده می‌شوند. اعلام داخل شیوه‌نامه به‌محض رسیدن شیوه‌نامه خوانده می‌شود، پس ممکن است صفحه یک فریم از نسخهٔ تاریک را نشان بدهد و بعد دست‌نخورده بماند. در موتورهای فیلتر فقط متا تگ و ویژگی style خوانده می‌شوند.

چه چیزهایی کمک می‌کنند: جفت رنگ‌های خوانا برای متن و زمینه، رنگ زمینه زیر متن، و کم‌بودن رنگ‌های درون‌خطی با `!important`.

## توسعه

Node.js نسخهٔ ۲۲ یا بالاتر.

```bash
npm install
npm run check          # بررسی‌های ایستا، بررسی نوع و آزمون‌های واحد
npm run build          # بستهٔ Chrome و Edge در dist/
npm run build:firefox  # بستهٔ Firefox در dist/
npm run lint:firefox   # بستهٔ Firefox را می‌سازد و لینتر افزونه را اجرا می‌کند
npm run test:browser   # Chromium واقعی؛ یک بار npx playwright install chromium را اجرا کنید
npm run test:firefox   # Firefox واقعی؛ باید نصب باشد
npm run test:perf      # بودجهٔ سرعت و اندازه
```

فایل `.npmrc` مقدار `ignore-scripts=true` دارد، پس نصب یک بسته هیچ‌وقت اسکریپت نصب آن را اجرا نمی‌کند.

بیشتر در [docs/TESTING.md](../../docs/TESTING.md) و [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) (به انگلیسی).

## پرسش‌های متداول

**آیا Tintly داده‌ام را جایی می‌فرستد؟** نه. حساب کاربری، آمارگیری و تنظیمات از راه دور ندارد. تنها درخواست‌هایش برای گرفتن شیوه‌نامه یا تصویر همان صفحه‌ای است که در آن هستید.

**صفحه‌ای بد دیده می‌شود. چه کنم؟** در پنجرهٔ نوار ابزار موتور دیگری را امتحان کنید یا Tintly را برای آن سایت خاموش کنید. سپس [فرم صفحه بد دیده می‌شود](https://github.com/ehsanenaloo/Tintly/issues/new?template=site_breakage.yml) را پر کنید. نشانی، حالت و موتور را بنویسید.

**چرا صفحه‌ای عوض نمی‌شود؟** ممکن است صفحه از پیش تاریک باشد، فقط یک طرح رنگ را بپذیرد یا از Tintly بخواهد کاری با آن نداشته باشد. ممکن است سایت خاموش باشد، یا مرورگر اجازهٔ اجرای افزونه را در آن صفحه ندهد، مثل صفحه‌های تنظیمات خود مرورگر.

**تفاوت «کاغذ» و E-ink چیست؟** هر دو صفحه‌ای آرام از کاغذ و جوهر برای خواندن می‌دهند. E-ink بدون رنگ شروع می‌شود. حالت کاغذ (Paper) کمی رنگ نگه می‌دارد و سفیدترین سفید و نور آبی را کم می‌کند. تنظیم «رنگ» برای هر دو قابل تغییر است.

**آیا می‌توانم Tintly را فقط روی چند سایت به کار ببرم؟** بله. فقط سایت‌هایی را که انتخاب می‌کنید روشن بگذارید یا سایت‌ها را یکی‌یکی خاموش کنید.

**روی گوشی کار می‌کند؟** هنوز آزمایش نشده است. Tintly برای مرورگرهای رایانه ساخته شده است. افزونه برای Firefox روی Android هم عرضه می‌شود، اما هنوز روی آن آزمایش نشده و ممکن است خوب کار نکند. Chrome و Edge فقط روی رایانه‌اند.
